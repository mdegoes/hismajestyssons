# social-engine/posts/

Archive of X posts drafted for **@HisMajestysSons** by the `x-repost` skill
(`.claude/skills/x-repost/`). Committed on purpose — a record of what was posted,
what was researched, and why.

```
posts/
├── research/
│   └── YYYY-MM-DD-<topic-slug>.md     # topic research briefs
└── YYYY-MM-DD-<post-slug>/
    ├── post.md      # final text + variants, alt text, credit, source, notes
    ├── image.png    # the rendered card (if the run built one)
    ├── card.html    # the filled card template (reproducible)
    ├── source.md    # what's being amplified, fit rationale, rubric scores, vetting
    └── PUBLISH.md   # copy-paste checklist for posting it by hand
```

Nothing here is loaded by the site, and `social-engine/` is excluded from the
GitHub Pages deploy. The skill never publishes to X — a human posts from the
package.
